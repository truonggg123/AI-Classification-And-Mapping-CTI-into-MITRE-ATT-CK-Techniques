1. BƯỚC 1: CHUẨN HÓA & KHỬ TRÙNG LẶP DỮ LIỆU (src/merge_datasets.py)
================================================================================
Mục đích: Đọc các file dữ liệu thô ở Bước 0, khử trùng lặp văn bản, ẩn mã Txxxx
để chống rò rỉ nhãn (Label Leakage), và xuất file CSV chuẩn 2 cột (Cleaned_Text, Labels).

- Bước 1.2: Tạo tập TRAM
    Command: python src/merge_datasets.py --target_dataset tram
    Raw Inputs : dataset/raw/TRAM dataset/multi_label.json & single_label.json
    EXACT OUTPUT: dataset/processed/tram/raw_merged.csv (8,508 mẫu)

- Bước 1.3: Tạo tập Joint (Hợp nhất cả 2 nguồn)
    Command: python src/merge_datasets.py --target_dataset joint
    Raw Inputs : dataset/raw/dataset.csv + dataset/raw/TRAM dataset/*.json
    EXACT OUTPUT: dataset/processed/joint/raw_merged.csv (21,452 mẫu)

      1. dataset/processed/cti_to_mitre/train.csv (10,345 mẫu - 80%)
      2. dataset/processed/cti_to_mitre/test.csv (2,599 mẫu - 20%)
      3. dataset/processed/cti_to_mitre/multilabel_binarizer.pkl (Binarizer 188 Active Labels)

- Bước 2.2: Tiền xử lý tập TRAM
    Command: python src/preprocessing.py --target_dataset tram
    Input: dataset/processed/tram/raw_merged.csv
    EXACT OUTPUTS:
      1. dataset/processed/tram/train.csv (6,803 mẫu - 80%)
      2. dataset/processed/tram/test.csv (1,705 mẫu - 20%)
      3. dataset/processed/tram/multilabel_binarizer.pkl (Binarizer 50 Active Labels)

- Bước 2.3: Tiền xử lý tập JOINT
    Command: python src/preprocessing.py --target_dataset joint
    Input: dataset/processed/joint/raw_merged.csv
    EXACT OUTPUTS:
      1. dataset/processed/joint/train.csv (17,161 mẫu - 80%)
      2. dataset/processed/joint/test.csv (4,291 mẫu - 20%)
      3. dataset/processed/joint/multilabel_binarizer.pkl (Binarizer 188 Active Labels)

3. BƯỚC 3: TĂNG CƯỜNG DỮ LIỆU MẪU HIẾM (src/augmentation.py)
================================================================================
Mục đích: Gia tăng số lượng mẫu cho các nhãn hiếm (minority classes) trên tập Train.
Sử dụng thuật toán Multi-Label Aware Greedy Resampling và Tập Bảo vệ Từ vựng TF-IDF.

Mốc Target Count tự động khớp theo Mean thực nghiệm:
  * CTI-to-MITRE : MEAN = 55 mẫu/nhãn  (Cân bằng 135 nhãn hiếm < 55)
  * TRAM         : MEAN = 151 mẫu/nhãn (Cân bằng 36 nhãn hiếm < 151)
  * JOINT        : MEAN = 95 mẫu/nhãn  (Cân bằng 138 nhãn hiếm < 95)

Các Chế Độ Augmentation (`--mode`):
  - `eda` : Cyber EDA (Phương pháp đề xuất)
  - `sr`  : Synonym Replacement
  - `ri`  : Random Insertion
  - `rs`  : Random Swap
  - `rd`  : Random Deletion

Lệnh Thực Thi & EXACT OUTPUTS:

- Chạy Cyber EDA cho CTI-to-MITRE:
    Command: python src/augmentation.py --train_file dataset/processed/cti_to_mitre/train.csv --mode eda --save_csv
    Input : dataset/processed/cti_to_mitre/train.csv
    EXACT OUTPUT: dataset/processed/cti_to_mitre/train_augmented_eda.csv (14,929 mẫu)

- Chạy Cyber EDA cho TRAM:
    Command: python src/augmentation.py --train_file dataset/processed/tram/train.csv --mode eda --save_csv
    Input : dataset/processed/tram/train.csv
    EXACT OUTPUT: dataset/processed/tram/train_augmented_eda.csv (8,981 mẫu)

- Chạy Cyber EDA cho JOINT:
    Command: python src/augmentation.py --train_file dataset/processed/joint/train.csv --mode eda --save_csv
    Input : dataset/processed/joint/train.csv
    EXACT OUTPUT: dataset/processed/joint/train_augmented_eda.csv (23,910 mẫu)

- Chạy các biến đổi Atomic (`sr`, `ri`, `rs`, `rd`):
    Command: python src/augmentation.py --train_file dataset/processed/cti_to_mitre/train.csv --mode sr --save_csv
    EXACT OUTPUT: dataset/processed/cti_to_mitre/train_augmented_sr.csv
